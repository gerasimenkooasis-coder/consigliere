КОНСИЛЬЕРИ — iPhone Web App

Это автономная мобильная PWA-версия для iPhone.

Установка:
1. Разместите папку на HTTPS-хостинге.
2. Откройте index.html через HTTPS в Safari.
3. Safari -> Поделиться -> На экран Домой.
4. Запускайте с иконки как отдельное приложение.

Важно: локальная история хранится в браузере устройства. Эта версия не содержит серверного AI и веб-поиска; она предназначена как быстрая мобильная версия.
